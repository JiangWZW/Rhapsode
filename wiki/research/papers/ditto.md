# DITTO: Self-Alignment for Arbitrary Role-Play

Lu et al., ACL 2024 | [arXiv](https://arxiv.org/abs/2401.12474) | [GitHub](https://github.com/OFA-Sys/Ditto) (213 stars)

Full paper title: *"Large Language Models are Superpositions of All Characters: Attaining Arbitrary Role-play via Self-Alignment"*

## Core idea

LLMs already contain rich character knowledge from pre-training. Instead of distilling from proprietary models (GPT-4), DITTO treats role-play as a variant of **reading comprehension**: the model reads a character's Wikipedia entry and generates in-character dialogue, using only its own capabilities. This "self-alignment" approach produces a training set of 4,000 characters -- 10x larger than prior work -- without any proprietary model dependency.

## Method

### Self-alignment pipeline

1. **Character knowledge collection** -- Gather Wikipedia articles and Wikidata properties for 4,000 characters (historical figures, fictional characters, public figures).
2. **Role-specific query generation** -- Generate character-relevant questions that probe identity, knowledge, and cognitive boundaries.
3. **Contrastive query generation** -- Generate questions designed to test whether the model can distinguish between characters (e.g., asking Beethoven about Mozart's works).
4. **Self-generated dialogue** -- The instruction-following LLM itself generates multi-turn role-play dialogues by "reading" the character's Wikipedia article and responding in character.
5. **Fine-tuning** -- SFT on the self-generated dialogue data.

### Cross-supervision experiment

DITTO presents the first cross-supervision study in role-play: training a weaker model on data generated by a stronger model (and vice versa). Key finding: **role-play styles are easily transferable** (even small models can teach style), but **role-specific knowledge is bounded by the model's intrinsic capabilities** (a small model can't teach a large model knowledge it doesn't have, and vice versa).

## WikiRoleEval benchmark

The most rigorous evaluation framework in this space, with three metrics:

| Metric | What it measures | Method |
|--------|-----------------|--------|
| **Consistent Role Identity** | Does the model maintain character identity across turns? | Multi-choice test -- an LLM judge picks which of 4 candidate characters the model is portraying |
| **Accurate Role-specific Knowledge** | Does the model provide factually correct character knowledge? | Evidence-based scoring -- LLM judge checks responses against Wikipedia evidence |
| **Unknown Question Rejection** | Does the model refuse questions outside the character's cognitive scope? | Binary classification -- manually annotated out-of-scope questions, LLM judge checks for rejection |

Evaluation uses GPT-4-Turbo as the judge, with temperature 0.2 and 3 repetitions for variance reduction.

## Key results

- DITTO outperforms all open-source role-play baselines across parameter scales
- Performance comparable to advanced proprietary chatbots (GPT-4, Qwen-Max)
- Cross-supervision confirms: style is cheap to acquire, knowledge is the bottleneck

## Code completeness

**Evaluation framework only** -- the repo provides:

- WikiRoleEval test data with evidence and rejection labels
- Scoring scripts (GPT-4 as judge)
- API call scripts for baseline generation (Together, Zhipu, Wenxin, Qwen APIs)
- Reference responses from GPT-4-Turbo

**Missing:** The README explicitly states *"We will soon release a reproduction recipe based on the latest Qwen series. Stay tuned!"* -- the self-alignment data generation and training pipeline are not released.

## Limitations

- Training pipeline not open-sourced (evaluation only)
- WikiRoleEval relies on GPT-4 as judge (~$30 per evaluation run)
- Self-alignment quality is bounded by the seed model's pre-training knowledge
- Primarily evaluated on well-known characters with rich Wikipedia entries; unclear how it handles obscure or original characters

## Relevance to Rhapsode

**Rank: #2 -- primary data generation method for Rhapsode's character training pipeline.**

Rhapsode uses local small LLMs with no cloud API budget for data generation. DITTO's self-alignment is the only surveyed approach that eliminates proprietary model dependency entirely. The reading-comprehension framing maps directly to feeding WorldGraph character profiles as context.

| Aspect | Applicability |
|--------|--------------|
| Self-alignment data generation | **Very High** -- the method for producing LoRA training data locally without GPT-4 |
| Reading-comprehension framing | **Very High** -- WorldGraph character nodes become the "articles" the model reads |
| WikiRoleEval | High -- adapt as quality gates (needs local judge model instead of GPT-4) |
| Cross-supervision insight | Medium -- style transfers easily from small models, knowledge doesn't; informs what goes in LoRA vs. prompt |
| Cognitive boundary testing | **Very High** -- maps to preventing NPCs from breaking world consistency |

**Key gap:** Training pipeline not open-sourced. Reimplementing DITTO's data generation on top of a local Qwen/LLaMA is the highest-value engineering task for Rhapsode's character system.
